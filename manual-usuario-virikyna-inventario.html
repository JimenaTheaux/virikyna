Manual de uso — Virikyna Inventario

Guía de uso de Virikyna Inventario, la app para el celular pensada para moverse por el local o el depósito: cargar y editar productos con la cámara del teléfono, y registrar una factura de un proveedor apenas llega la mercadería.

Cajero y Admin pueden hacer esta acción
Solo Admin acción restringida al administrador

Cómo usar este manual

  • Usá el buscador de la izquierda para filtrar directamente las secciones que mencionan lo que estás buscando.
  • Podés imprimir este manual o guardarlo como PDF desde el navegador.
  • Este archivo funciona sin conexión a internet, salvo por la tipografía (si no carga, se usa una fuente del sistema equivalente).

Pantalla 1

Inventario

Catálogo de productos, precios y stock por ubicación (Local y Depósito), pensado para usar con una mano mientras se camina por el local.

Elementos de la pantalla

ElementoQué es
BuscadorFiltra por nombre, marca o código, a medida que se escribe. Queda fijo arriba mientras se baja por la lista.
Botón de cámaraEscanea un código de barras: el número leído queda escrito en el buscador y la lista se filtra con ese producto, sin necesidad de tipearlo.
Botón de porcentajeAbre la actualización masiva de precios.
Tarjetas de productoCada producto con su nombre, marca y código (o el código interno si no tiene código de barras), proveedor, estado, stock en Local/Depósito y precio de venta. Tocando la tarjeta se abre para editar.
Botón "+" (abajo a la derecha)Da de alta un producto nuevo.

Elementos de la ficha de producto

CampoQué significa
Código de barrasEs el primer campo. Se puede escanear con la cámara o tipear. Si ya existe un producto con ese código, avisa al instante y ofrece el botón "Editar existente" para ir a ese producto en vez de crear uno repetido.
NombreObligatorio. Si se intenta guardar sin nombre, el aviso aparece debajo de este campo y la pantalla sube sola hasta él.
ProveedorAl elegirlo en un producto nuevo, los márgenes se autocompletan con los del proveedor.
Costo, Margen 1 y Margen 2El precio de venta se calcula solo: Costo × (1 + Margen 1) × (1 + Margen 2) × (1 + IVA 21%). Solo Admin puede editar los márgenes.
Stock mínimoUmbral para la alerta de stock bajo.
Stock por ubicaciónLocal y Depósito por separado, con un botón "Ajustar" en cada uno.
Cancelar y GuardarQuedan siempre visibles al pie de la ficha, aunque el formulario sea largo — no hace falta bajar hasta el final para guardar.

4Tocar para editar
  1. Tocá el ícono de cámara y apuntá al código de barras del producto. Mantené el teléfono quieto un instante: la app lee el código más de una vez para confirmarlo antes de aceptarlo.
  2. Si el producto existe, aparece en la lista de resultados — tocalo para abrir su ficha.
  3. Si no existe, la lista queda vacía y aparece el botón "Crear producto con este código", con el código ya cargado en la ficha.
  4. Completá o corregí los datos y guardá.

¿Escaneaste un producto que sabés que está cargado y no aparece? Compará el número que quedó escrito en el buscador con el de la etiqueta del producto. Si no coinciden, la cámara leyó mal: volvé a escanear con mejor luz (el botón 💡 prende la linterna) o buscalo por nombre. No lo des de alta de nuevo.

Flujo paso a paso — actualización masiva de precios

  1. Tocá el botón de porcentaje.
  2. Elegí el modo: todos los productos de un proveedor, o una selección puntual.
  3. Cargá el porcentaje: positivo para aumentar, negativo para bajar.
  4. Aplicá — el precio de venta de cada producto afectado se recalcula solo.

Cosas importantes a tener en cuenta

Ajustar stock manualmente (sumar o restar unidades a mano) es Solo Admin. Siempre pide un motivo: Rotura, Pérdida, Corrección de conteo físico, u Otro con detalle.

Editar Margen 1 y Margen 2 de un producto también es Solo Admin. Como Cajero se puede dar de alta productos y cargar el costo, pero no fijar el margen de ganancia.

Un producto marcado "Inactivo" se conserva para el historial, pero deja de aparecer en las búsquedas de venta.

Pantalla 2

Facturas de compra

Registra una factura de un proveedor apenas llega la mercadería, actualizando el stock automáticamente por cada producto.

Elementos de la pantalla

ElementoQué es
Datos del comprobanteProveedor, tipo (Factura, Remito, Cupón, Nota de crédito o Nota de débito), letra, punto de venta, número, fecha y forma de pago (Contado o Cuenta corriente).
ÍtemsUna tarjeta por producto, con los campos en este orden: código de barras (con botón de cámara), producto, marca, cantidad, precio unitario sin IVA, descuento y a qué depósito entra (Local o Depósito). Al encontrar el producto se completan solos el nombre, la marca y el precio (último costo).
Aviso de códigoAparece dentro de la tarjeta cuando un código escaneado no se pudo vincular a un producto: si no existe, si el producto está inactivo, o si no hay conexión. Ver más abajo qué hacer en cada caso.
Botón "Agregar ítem"Debajo de la lista de ítems. Agrega una tarjeta nueva y deja el cursor listo en su código de barras.
TotalesSubtotal, descuento, IVA (21%), saldo pendiente y total, calculados en vivo a medida que se cargan los ítems.

Flujo paso a paso

  1. Elegí el proveedor y el tipo de comprobante.
  2. Cargá letra, punto de venta, número, fecha y forma de pago.
  3. Por cada producto, escaneá el código con la cámara (o tipealo) o buscalo por nombre o marca en el campo "Producto". Si lo encuentra, se completan solos el nombre, la marca y el precio.
  4. Cargá cantidad, precio, descuento y a qué depósito entra.
  5. Tocá "Agregar ítem" para el siguiente producto de la factura.
  6. Revisá los totales y tocá "Guardar factura" — el stock de cada producto se actualiza solo.

Si el código escaneado no aparece

La app nunca da de alta un producto por su cuenta: muestra un aviso dentro de la tarjeta con el número leído, y vos elegís qué hacer.

AvisoQué hacer
"No encontramos el código…"Primero compará el número del aviso con el de la etiqueta. Si el producto ya está cargado, tocá "Buscar por nombre" y elegilo de la lista. Si de verdad es mercadería nueva, tocá "Crear producto nuevo": se abre la ficha con el código ya cargado y, al guardarla, el ítem queda vinculado a ese producto.
"…está inactivo"El código es de un producto dado de baja. Tocá "Usarlo igual" para cargarlo en la factura de todos modos, o "Buscar otro".
"Sin conexión…"No se pudo consultar el catálogo. Cuando vuelva internet, tocá "Reintentar".

Si al crear un producto nuevo desde la factura el código ya existe en el catálogo, la ficha lo avisa y ofrece el botón "Usar este producto existente": el ítem queda vinculado a ese producto y no se crea uno repetido.

Con lector de códigos Bluetooth

  1. Tocá el campo "Código de barras" del primer ítem y escaneá.
  2. Si el producto existe, se completa y el cursor pasa solo al código del ítem siguiente (si era el último, se agrega uno nuevo).
  3. Seguí escaneando: se pueden cargar varios productos seguidos sin tocar la pantalla. Después ajustá la cantidad de cada uno si no es 1.

Cosas importantes a tener en cuenta

  • Si se sale de esta pantalla con datos cargados sin guardar, se pide confirmación antes de perderlos.
  • La factura se guarda solo con el botón "Guardar factura". Apretar Enter o "Ir" en el teclado (o el Enter del lector) desde cualquier campo no la guarda ni borra lo cargado.
  • Si un ítem tiene código, precio o marca cargados pero no tiene producto elegido (o tiene cantidad 0), la factura no se guarda: la tarjeta se marca en rojo con el aviso "El ítem N no tiene producto seleccionado" y la pantalla va hasta ella. Elegí el producto o quitá el ítem con el tachito. Las tarjetas totalmente vacías se ignoran.
  • Desde acá no se puede ver el listado de facturas ya cargadas, ni registrar un pago a proveedor — eso se hace desde la Caja o desde Gestión.
